## 요약

**2026-09-14에 iOS 27(24A437)과 Xcode 27(27A266a)이 정식 출시**됨. 이 저장소의 [Xcode 27의 에이전트 표면](./2026-08-26-xcode-27-agent-surface.md)이 **베타 6 스냅샷**이었고 그 문서 자신이 정식 출시 때 대조하라고 적어뒀으므로, 이 문서는 새 기능 목록이 아니라 **그 대조 결과**임. 결론 셋임. 첫째, 에이전트 표면은 빠진 항목 없이 그대로 갔고 베타에서 걸리던 것 둘(계획 확인 바 충돌, Apple 스킬이 Codex에 안 보이던 문제)이 **해결 항목으로 올라옴**. 둘째, **워크스페이스 없는 MCP 서버는 정식에서도 여전히 early preview**이고 파일시스템 보안 계층도 여전히 **설정에서 켜야 하는 것**임. 셋째, 요구사항이 올라갔음. **macOS Tahoe 26.6 이상**이고(베타 문서에 26.4로 적어둔 값이 틀림), **2027-04부터 iOS 27 SDK가 App Store 제출 최소 요건**이 됨.

## 무엇이 언제 나왔나

| 날짜 | 일어난 일 |
|---|---|
| **2026-09-09** | Xcode 27 RC(27A266a) 배포. 27 계열 OS에 대한 **App Store 제출 개시** |
| **2026-09-14** | iOS·iPadOS 27.0(24A437), macOS 27.0(26A428), tvOS 27.0(24J361), visionOS 27.0(24M362), watchOS 27.0(24R364), **Xcode 27 정식(27A266a)** |
| **2026-09-16** | 27.2 베타 일괄 배포(Xcode 27.2는 27B5019j) |
| 예고 | **iPhone Duo가 10-23 출시되고 iOS 27.1로 돎.** Xcode 27.1이 그 SDK와 시뮬레이터를 붙이고 베타는 "이달 말" |

RC 빌드 번호와 정식 빌드 번호가 **27A266a로 같음**. RC로 검증한 결과를 다시 돌릴 필요는 없다는 뜻임.

## 베타 문서에서 고쳐야 할 값 하나

정식 릴리스 노트의 개요 문장임.

> "Xcode 27 includes Swift 6.4 and SDKs for iOS 27, iPadOS 27, tvOS 27, watchOS 27, macOS 27, and visionOS 27. Xcode 27 supports on-device debugging in iOS 17 and later, tvOS 17 and later, watchOS 10 and later, and visionOS. **Xcode 27 requires a Mac running macOS Tahoe 26.6 or later.**"

Swift 6.4와 27 계열 SDK는 베타 6 기록 그대로인데 **호스트 macOS 요건이 26.6**임. [Xcode 27의 에이전트 표면](./2026-08-26-xcode-27-agent-surface.md)이 26.4로 적어둔 값은 베타 시점 값이고 지금은 맞지 않음. 빌드 머신 macOS를 26.4·26.5에 고정해 둔 CI가 있으면 여기서 막힘.

Apple Silicon 전용이라는 조건은 그대로 유효하고, 범위가 OS로도 넓어짐. 개발자 공지가 **macOS 26이 Intel과 Rosetta를 지원하는 마지막 릴리스**이고 macOS 27은 Apple Silicon 전용이므로 빌드 아키텍처를 **arm64 단독**으로 두라고 적음.

## 확정된 것, 베타에서 걸리던 둘이 해결됨

베타 문서가 경고로 적어둔 항목 둘이 정식 릴리스 노트의 해결 목록에 있음.

> "Fixed: If the plan-mode confirmation bar ("Implement the plan?" with Yes/No buttons) appears while the agent is still streaming a response, clicking either button may trigger a new agent turn on top of the in-flight one, leaving the conversation in an inconsistent state. (178673449)"

> "Fixed: Apple-authored agent skills may not be available to Codex. (179171480)"

앞의 것은 **회피법(응답이 끝난 뒤 누르기)을 더 지킬 필요가 없다**는 뜻임. 뒤의 것이 더 중요한데, 베타 문서가 이 항목을 두고 "어느 에이전트에 무엇이 노출되는지가 균일하지 않을 수 있다"는 신호로 읽으라고 적었음. **그 신호 자체는 이번 수정으로 사라짐.** 다만 특정 버그 하나가 고쳐진 것이지 노출 균일성이 보장된다는 서술은 릴리스 노트 어디에도 없으므로, 서드파티 에이전트를 붙일 때 스킬이 실제로 보이는지는 여전히 직접 확인해야 함.

에이전트 플러그인 관련 해결 항목이 하나 더 있음. **ACP 에이전트를 플러그인으로 추가했다가 제거해도 Xcode를 재실행하기 전까지 UI에 남던 문제**(178771195)가 고쳐짐.

## 아직 확정이 아닌 것

여기가 정식 출시를 대조하는 이유임. **정식이 됐다고 전부 정식이 된 게 아님.**

**워크스페이스 없는 MCP 서버는 여전히 early preview임.** 문장이 베타 5 때 표현 그대로 남아 있음.

> "Xcode 27 Beta 5 adds a preview of a new MCP server experience that runs without requiring an open Xcode workspace. This new experience also allows you to grant code-signed agents permission to use projects within a directory tree for extended periods of time without being asked for additional permissions. In this early preview, some aspects of the `xcrun mcp-server` command line utility may not work in all configurations, and some settings or permissions may occasionally require relaunching Xcode or rebooting your machine to apply. (181836944)"

즉 **장기 권한 부여 모델이 프리뷰 딱지를 단 채로 정식 빌드에 들어와 있음.** 무인 환경에 `xcrun mcp-server`를 깔아 CI를 굴릴 계획이면 이 상태를 전제로 잡아야 함.

**파일시스템 보안 계층도 기본값이 아님.** 문장이 그대로임.

> "Coding Intelligence now includes a new security layer that monitors and controls filesystem access by coding agents and any processes they spawn. This can be enabled in Coding Intelligence settings. (178289431)"

정리하면 정식 출시로 **권한을 넓히는 쪽은 켜진 채로 왔고 감시하는 쪽은 꺼진 채로 왔음.** [사람이 에이전트 명령 승인에서 위협 3건 중 1건을 놓친다](../security/2026-08-05-agent-approval-miss-rates.md)의 결론, 즉 승인 정확도를 올리는 것보다 위험한 경로를 아예 승인 대상에서 빼는 게 싸다는 판단이 이 설정 화면에서 그대로 필요함. 이건 설치 직후 한 번 열어보면 끝나는 일임.

## 새로 생긴 기한

베타 기간에는 없던 항목임. 2026-09-09 공지가 **2027-04부터의 최소 SDK 요건**을 못 박음.

| 대상 | 요건 |
|---|---|
| iOS·iPadOS 앱 | iOS 27 · iPadOS 27 SDK 이상 |
| tvOS 앱 | tvOS 27 SDK 이상 |
| visionOS 앱 | visionOS 27 SDK 이상 |
| watchOS 앱 | watchOS 27 SDK 이상 |

이게 에이전트 얘기로 이어지는 지점이 있음. **2027-04 이후에는 App Store에 올릴 앱이 어차피 Xcode 27 툴체인을 지나가야 함.** 26.3의 Claude Agent SDK로 충분하니 27은 나중에 보겠다는 계획이 성립하는 기간이 약 7개월로 정해졌다는 뜻임. 같은 창에 걸리는 다른 이전 작업도 있음. **On-Demand Resources가 폐기되고 Background Assets로 넘어가고**, **ld64 classic 링커가 제거돼 `-ld_classic`이 더는 안 먹힘.**

## Foundation Models 쪽은 숫자가 그대로임

[Foundation Models 실전](../practices/2026-08-21-foundation-models-in-practice.md)이 베타 문서 기준으로 적어둔 온디바이스 컨텍스트 수치를 오늘 다시 확인함. 문서 문장이 그대로임.

> "Apple's on-device foundation model has a context window of 4096 tokens per session, with a token representing each word, or partial word."

**4,096은 정식 출시 뒤에도 유지됨.** 그쪽 문서의 한국어 토크나이저 계산은 그대로 쓸 수 있음. 반면 **PCC의 32K, 일일 한도 API, 무료 구간 조건은 이번에 재확인하지 못했음.** 그 절은 여전히 베타 시점 기록으로 두고 봐야 함.

## 짚어야 할 것

- **릴리스 노트와 개발자 공지만 읽었고 Xcode 27을 직접 설치해 보지 않았음.** 프리뷰로 남은 항목이 실제로 어떻게 동작하는지는 확인하지 못했음
- **"해결됨"은 Apple이 해결로 분류했다는 뜻임.** 재현해서 확인한 것이 아님
- 릴리스 노트의 해결 항목은 베타 구간에서 고쳐진 것이 누적돼 있음. **어느 베타에서 고쳐졌는지는 항목마다 표기되지 않아 갈라내지 못했음**
- **iOS 27 자체의 Apple Intelligence 변경은 이 문서에서 다루지 않았음.** 개발자 API 표면이 아니라 사용자 기능 쪽이고, 뉴스룸 본문을 읽지 않았음
- iPhone Duo와 iOS 27.1은 **공지에 적힌 예고**임. 27.1 SDK가 실제로 무엇을 바꾸는지는 베타가 나와야 알 수 있음
- **PCC 32K와 무료 구간 조건은 이번에 확인할 수 없었음.** 해당 문서 페이지를 열지 못했고, 추정해서 적지 않았음

## 유효기간

**2026-09-17 확인 기준**임. 27.1과 27.2가 이미 베타로 돌고 있어 릴리스 노트가 계속 늘어남. 다시 볼 때 확인할 것은 둘임. **`xcrun mcp-server`가 early preview를 벗어났는지**, 그리고 **파일시스템 보안 계층이 기본값으로 바뀌었는지**. 둘 다 릴리스 노트의 Coding Intelligence 절만 보면 잡힘. 2027-04 최소 SDK 기한은 그때까지 유효한 날짜이므로 이 문서에서 가장 오래 남는 항목임.
